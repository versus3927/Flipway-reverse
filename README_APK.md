# ГРАВИ-РАН 3D — как собрать APK в Android Studio

Игра написана на WebGL (это OpenGL ES в браузере) и работает как есть на любом
телефоне/ПК. Чтобы получить нативный **APK-файл**, оберни её через **Capacitor** —
весь 3D-движок, звук и управление будут работать нативно в WebView с аппаратным
ускорением OpenGL ES.

## Быстрый вариант (5 минут)

```bash
# 1. Собери веб-версию
npm run build            # появится папка dist/

# 2. Установи Capacitor
npm install @capacitor/core @capacitor/cli @capacitor/android

# 3. Инициализируй проект приложения
npx cap init "ГРАВИ-РАН 3D" com.you.graviran --web-dir=dist

# 4. Добавь Android-платформу
npx cap add android

# 5. Скопируй сборку в android-проект
npx cap sync
```

## Дальше в Android Studio

1. **File → Open** → выбери появившуюся папку `android/`.
2. Дождись синхронизации Gradle (используется твой установленный SDK).
3. **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый APK будет в `android/app/build/outputs/apk/debug/app-debug.apk`
   (или запусти сразу на телефоне через кнопку **Run**).

## После изменения кода игры

```bash
npm run build && npx cap sync
```
и снова Build APK в Android Studio.

## Что уже настроено в игре

- `manifest.webmanifest` + иконка 512px (PWA: можно «Добавить на главный экран» без APK).
- Полноэкранный режим, запрет зума, touch-управление (свайпы/тапы), автопауза при сворачивании.
- Локальное сохранение рекорда.

## Управление

| Действие | Телефон | ПК |
|---|---|---|
| Смена дорожки | свайп ← → или кнопки | стрелки / A, D |
| Сальто на потолок / прыжок | тап или кнопка | Пробел / W / ↑ |
| **Кувырок под барьером** | свайп вниз / кнопка «КУВЫРОК» | S / ↓ |
| Пауза | кнопка на экране | P / Esc |

## Локации (случайный порядок, 6 штук)

1. **НЕОН-СИТИ** — тёмная подземка, неон, встречные поезда
2. **АЛЫЙ КАНЬОН** — скалы, кактусы, товарняки
3. **ЛЕДЯНАЯ ПЕЩЕРА** — сосульки сверху и снизу
4. **МОПС-СТРИТ** — мопсы перебегают дорогу и висят на шариках
5. **ЗАМОК ДРАКОНОВ** — стена перекрывает дорогу, уходишь на 4-ю улицу
   у белого замка: рва, кусты, вазы, поручни, потолка нет (тап = прыжок),
   навстречу летят драконы
6. **СОЛНЕЧНЫЙ ПАССАЖ** — светлая улица под стеклянной крышей, пальмы,
   фонтаны, солнечные лучи

## Система урона

- **Лёгкое задевание** (вскользь, край препятствия): экран трясёт, над головой
  кружат звёздочки, скорость сбрасывается. Включается окно **20 секунд «НА ГРАНИ»**
  (таймер и янтарная рамка на экране).
- **Второе задевание в эти 20 секунд** — смерть.
- Если продержался 20 секунд — «ПРОНЕСЛО!», состояние снимается.
- Прямой удар в лоб (встречный поезд/дракон, полное попадание в препятствие) —
  смерть сразу.

## Поезда

- Стоячие на путях, медленные и быстрые — **на крышу любого можно попасть**.
- Способ посадки: бежишь **по потолку** над составом и делаешь **сальто (тап)** —
  персонаж приземляется точно на крышу, а не проваливается сквозь корпус.
- **Прыжок специально низкий** (1.95 против крыши 2.95) — он для препятствий,
  запрыгнуть им на поезд нельзя.
- Встречные экспрессы летят лоб в лоб — от них только уворот.

## Графика

- WebGL / OpenGL ES, bloom-постобработка (UnrealBloomPass), ACES-тонмаппинг
- Динамические тени (авто-отключение на слабых устройствах), контровой свет,
  персональная подсветка героя, объёмные лучи солнца
- Персонаж — чиби-боец в стиле Standoff 2 (балаклава, тактические очки,
  жилет, кепка козырьком назад, грави-ранец)
